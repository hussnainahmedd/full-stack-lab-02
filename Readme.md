## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- VS Code

## Concepts Covered
- JavaScript Objects
- Arithmetic Operators (`+`, `-`, `*`, `/`, `%`)
- Comparison Operators (`>`, `<`, `>=`, `<=`, `===`, `!==`)
- Logical Operators (`&&`, `||`, `!`)
- Conditional Statements (`if`, `else if`, `else`)
- Loops (`for...in`)
- DOM Manipulation (`innerHTML`)
- Variable Hoisting (`var` vs `let`) & Debugging

## Project Description
This project extends the Lab 02 webpage with a fully functional JavaScript backend. It evaluates a student's performance dynamically by calculating total marks, percentages, and grades. It also applies complex logical conditions to determine pass/fail status, academic warnings, and merit scholarship eligibility, generating a beautifully styled final report directly in the browser.
